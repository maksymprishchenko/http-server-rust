# HTTP Server in Rust

## Опис проєкту

Даний проєкт є реалізацією простого HTTP-сервера мовою програмування Rust.

Сервер підтримує:
- HTTP GET requests
- HTTP POST requests
- обробку помилок
- передачу HTML-сторінок
- роботу через TCP-з'єднання

Проєкт створено в рамках курсової роботи з низькорівневого програмування.

---

## Технології

- Rust
- TCP
- HTTP/1.1
- GitHub

---

## Структура проєкту

- src/main.rs — основна логіка HTTP-сервера
- index.html — головна HTML-сторінка
- about.html — інформаційна сторінка
- Cargo.toml — конфігурація Rust-проєкту

---

## Запуск проєкту

cargo run

Сервер запускається за адресою:

127.0.0.1:7878
